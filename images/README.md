Zet hier je eigen foto's neer, met exact deze bestandsnamen:

- hero.jpg       (de grote foto bovenaan, naast "Van script naar scherm")
- actueel-1.jpg
- actueel-2.jpg
- actueel-3.jpg

Ze verschijnen automatisch op de website. Je hoeft niet alle vier te
gebruiken — een ontbrekende foto toont gewoon de bestaande plaatshouder
(bij "hero" de illustratie, bij "actueel" een lege plek) in plaats van een
foutmelding.

Wil je een foto verschuiven of inzoomen nadat je ze geüpload hebt? Ga naar
jouw-site.netlify.app/beheer.html (of storyshot.be/beheer.html), log in met
het beheerwachtwoord (ADMIN_PASSWORD, ingesteld bij Netlify → Environment
variables), en gebruik de schuifregelaars.
